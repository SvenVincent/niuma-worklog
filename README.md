## 它算的是什么

不是通用的「21.75 天 × 8h」折算，而是照公司工资单的口径：

- **时薪** = 基本工资 ÷ **当月法定工作日** ÷ 8h
- **加班三档**：平时 1.5 倍、假期里非法定那天 2 倍、法定节假日当天 3 倍
- **综合工时制按月结算**：月标准工时 = 当月法定工作日 × 8h，超出部分算平时加班
- **补贴逐项**：保税区补贴（当日工时达门槛）、夜班补贴、全勤奖（实际工时 ≥ 计划班次 × 11h）
- **月度奖金** = 产量 × 岗位单价 − 基本工资 − 总加班费 + 各项补贴
- **个税** =（申报收入 − 5000）× 3%，申报收入 = 税前应发 − 房租 − 商业险

这些规则写在 App 里、也能在官网页逐条看到。**口径优先于美观**：改任何界面都不能改变工资单数字，
改完必须能拿真实工资单回归（2026-06 与 07 两个月的公司工资单已逐行核对过）。

## 数据在哪

- 账号、考勤、产量、奖罚、扣款、设置存在 **Cloudflare D1**；登录态在 KV；头像与安装包在 R2。
- 本机只留三类东西：按账号的即时缓存、离线改动队列、界面偏好。
- 断网照常打卡，联网自动补传；「我的 → 同步状态」会明确列出「本机有 N 条云端没有」并可一键补传。
- 这是**个人记录工具**，与任何公司无关，也不是公司的考勤系统；没有广告、没有埋点统计。
